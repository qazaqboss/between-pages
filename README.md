# Between Pages

Сайт-визитка бренда магнитных закладок для книг (Алматы, Казахстан).

Закладка перегибается через край страницы и держится с двух сторон: снаружи иллюстрация,
внутри — карточка читателя (название, даты, строки для мыслей).

Иллюстрации взяты из производственного макета `закладки.pdf`: страницы рендерятся
`pdftoppm -r 300`, каждая закладка вырезается скриптом, фон делается прозрачным.
В макете каждая закладка — пара половинок: иллюстрация и карточка читателя, которые
смыкаются на странице.

**Live:** https://between-pages-vert.vercel.app/  
**Зеркало:** https://qazaqboss.github.io/between-pages/ (GitHub Pages)

Одностраничник без сборки: `index.html` + иллюстрации в `assets/`. Открывается двойным кликом,
деплой — обычный статический хостинг или GitHub Pages.

## Структура страницы

| Секция | Что внутри |
|---|---|
| Hero | Логотип, слоган «Между страницами живёшь ты», веер из четырёх закладок |
| Коллекции | 5 коллекций; клик фильтрует каталог |
| Каталог | 10 закладок в карточках |
| Наборы | 4 готовых набора + «Собери свой» |
| О бренде | Текст бренда и спецификация продукта |
| Как заказать | 3 шага, оплата Kaspi, самовывоз или курьер Казпочты |
| Отзывы, контакты | WhatsApp / Telegram / Instagram, блок для опта |
| Корзина | Добавление из каталога и наборов, счётчик, панель с итогом, отправка заказа одним сообщением в WhatsApp |

## Корзина

Без бэкенда. Состав лежит в `localStorage` (ключ `bp-cart`), товар описан прямо в разметке
атрибутами `data-id / data-name / data-price / data-img` на карточке каталога и набора.
Кнопка «Отправить заказ в WhatsApp» собирает `wa.me/77011118481?text=...` со списком,
количеством, итогом и способом получения.

Количество выбирается прямо в карточке: счётчик и подпись «В корзине: N шт.» строятся
скриптом из тех же атрибутов. Добавить товар — значит добавить карточку с этими четырьмя
атрибутами: корзина и счётчик подхватят её сами, править скрипт не нужно.

## Что заменить на реальные данные

- Телефон и ники в секции «Контакты» (сейчас `+7 700 000 00 00`, `@betweenpages`).
- Цены в каталоге и наборах (сейчас 1 900 ₸ за закладку, 2 000 ₸ за «Рояль»).
- Цены «Скрипки» и «Домбры» поставлены по общему правилу — 1 900 ₸.
- **События в афише — примеры структуры.** Даты, адреса и число мест нужно заменить своими.

## Стиль

Тёплый пергамент и редакционная типографика — по гайду `DESIGN (2).md`.

| Роль | Значение |
|---|---|
| Холст | `#fdf6ee` |
| Вторая поверхность (навигация, чередующиеся секции) | `#f0e6dc` |
| Карточки | `#ffffff` |
| Заголовки | `#2b180a` |
| Основной текст | `#21201c`, вторичный `#7f6e60`, третичный `#94877c` |
| Волосяные линии | `#d9cfc3` |
| Кнопка | `#3e2407` + персиковое свечение `#fed0b3` |
| Акцент | `#ff5c00` (метки) и `#f65726` (цены в составе, «осталось мест») |

Шрифты: **Cormorant Garamond 300** для заголовков (замена Martina Plantijn),
**Inter** для всего текста и интерфейса, **Roboto Mono** — только для строк характеристик.
Правила, которые держат систему:

- Заливка есть только у каштановой кнопки, и вокруг неё персиковое свечение вместо тени.
  Остальные кнопки — контурные, радиусы только 4 / 8 / 12 / 16 / 70 px.
- Никаких теней у карточек: разделение делают волосяная рамка и смена поверхности.
- Каждая секция открывается по одной схеме: метка → двухстрочный заголовок, вторая строка
  курсивом → один абзац шириной до 640 px.
- Оранжевый — одно-два попадания на экран, никогда не заливкой.
- Серифом набираются только заголовки; всё мельче 20 px — Inter.
- Герой — россыпь белых карточек вокруг центрального заголовка. Ниже 1180 px они
  переносятся скриптом в обычную сетку под заголовком.

## Превью ссылки (Open Graph)

При пересылке ссылки в WhatsApp, Telegram и соцсети показывается баннер
`assets/og-cover.jpg` (1200 × 630, 128 КБ), заголовок и описание из `<meta>` в `index.html`.

Исходник баннера — `assets/og-cover-source.html`. Перерисовать после правок:

```sh
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --disable-gpu \
  --force-device-scale-factor=2 --window-size=1200,630 --virtual-time-budget=8000 \
  --screenshot=og2x.png assets/og-cover-source.html
sips -z 630 1200 og2x.png && sips -s format jpeg -s formatOptions 82 og2x.png --out assets/og-cover.jpg
```

Кэш превью: после замены картинки WhatsApp и Telegram какое-то время отдают старую.
Сбросить — Facebook Sharing Debugger, а в Telegram написать боту @WebpageBot.
